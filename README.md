# Glorb

Electric remote-control art car for Burning Man.

## Quick stats

- **Width:** 1800 mm
- **Length:** 4000 mm
- **Battery box (under floor):** 1800 × 1016 × 450 mm
- **Speed:** ~5 mph
- **Total weight (built):** ~3960 lbs
- **Trailer payload needed:** 7000 lb (Big Tex 70CH was 5000 lb — upgrade required)
- **Total spend to date:** $92,980.39

## Current build

Burning Man 2026 theme: **giant glowing broom**. See [broom/DESIGN.md](broom/DESIGN.md).
