# Archive

Preserved-as-is content from the Google Drive folder `Glorb the Beignet Max Pro 2`. Most of this is git-ignored (large binaries) — see `.gitignore` at the repo root.

## What's here

| Folder | Contents | Tracked in git? |
| --- | --- | :---: |
| [pics/](pics/) | 227 photos & videos of the build (1.4 GB) | ❌ |
| [design/](design/) | 2023 panel takeoffs (C4D + AI vector files), Inspo references, app submission PSDs, design braindump docx (240+ MB) | ❌ |
| [dmv/](dmv/) | DMV applications by year with renders | ❌ |
| [specs-photos/](../archive/specs-photos/) | Reference photos from the cart spec docs | ❌ |
| [org/](org/) | Project history, build lists, improvements docs | ✅ |

The main extracted content lives in proper markdown elsewhere:

- Project history → [../history.md](../history.md)
- Camp roster → [../logistics/camp-2026.md](../logistics/camp-2026.md)
- Vinyl panel order → [../materials/vinyl.md](../materials/vinyl.md)

## Files inside `dmv/`

`dmv/2020/`, `dmv/2022/`, `dmv/2023/` — each contains the year's submitted DMV application docx + day/night renders. The 2024 application is inside `dmv/2023/` (filed alongside the prior year's materials).

## Files inside `design/`

- `2023-panel-design/` — Cinema 4D scene (`artcar2.c4d`), Illustrator panel takeoffs (`230803 - Glorb panel takeoffs.ai`), individual panel JPGs, wheelcover textures, the panel vinyl order spreadsheet
- `inspo/` — steel framing reference photos
- `app-submission/` — the PSD master files used for the 2023 DMV renders (large)
- `design-braindump.docx` — 33 MB design braindump
