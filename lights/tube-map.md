## Labeling scheme

Label every tube at **both ends** with its tube ID and its group. Example flag on a tube: `L05 / G2` = tube L05, group 2. Within a group the data chain runs **serpentine**: the tube nearest the Angio is the DIN head; flip alternate tubes so DOUT→DIN hops stay short, then reverse those strands in software.

```
Angio port ─[330–470Ω]─▶ DIN[tube a] ─DOUT─▶ DIN[tube b] ─▶ DIN[tube c] ─▶ DIN[tube d]   (one group)
```

## Install + test sequence

Do it **one group at a time**. Recommended order below finishes one Angio before moving to the next, so each controller + its network config is validated end-to-end. **Start with G15 (Back Angio A3)** as the very first group — it doubles as the open *bench-test-SM16703-on-Angio-8* check.

For each group: hang the 4 tubes → chain data (serpentine) → tap +24 V + shared GND → label both ends → ping me to light it from software → confirm all 4 tubes + color order → check the box.
