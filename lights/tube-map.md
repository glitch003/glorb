# Broom LED tube map — groups, Angios, lines, universes

> **Generated by [tube_map.py](tube_map.py) — do not hand-edit.** Change the knobs in that script and re-run.

**136 tubes** in **34 groups** of 4 across **5 Angio-8s**. Each Angio drives **2 data lines** of 3–4 chained groups (one line = one Angio port, up to 640 px).

Chip **SM16703**, color order **RGB**, transport **sACN / E1.31** in WLED *Multi* mode: each Angio owns one pixel space (lines concatenated in order), packed 170 px/universe from its start universe. A group can span a universe boundary — address by pixel offset, not universe.

## Labeling scheme

Label every tube at **both ends** with its tube ID and its group. Example flag on a tube: `L05 / G2` = tube L05, group 2. Within a group the data chain runs **serpentine**: the tube nearest the data source is the DIN head; flip alternate tubes so DOUT→DIN hops stay short, then reverse those strands in software. Chained groups continue the same data line: the last tube's DOUT feeds the next group's `data_in` tube.

```
Angio port ─[330–470Ω]─▶ G_a (4 tubes serpentine) ─DOUT─▶ G_b ─▶ G_c [─▶ G_d]   (one line, 3–4 groups)
```

## WLED / Angio config (per board)

Run **[angio_setup.py](angio_setup.py)** to configure a board uniformly from this map — e.g. `python3 angio_setup.py D` (or `--ip x.x.x.x` if not in the map yet). It sets: **output 1 = line 1** (start 0), **output 2 = line 2** (start = line 1 px), GPIOs from the per-line `pin` field in the map (`ANGIO_PINS` in this script — default 13/12, **D is plugged 12/13**); E1.31 DMX mode *Multi RGB*, start universe per the table above, port 5568, multicast on, force-max-brightness on; **boot default = no preset, 5% brightness** (so an offline boot can't burn real power); then reboots + verifies.

For each group: hang the 4 tubes → chain data (serpentine) → tap +24 V + shared GND → label both ends → ping me to light it from software → confirm all 4 tubes + color order → check the box.
